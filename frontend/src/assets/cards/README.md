# Card artwork

The UI currently renders CSS fallback cards. To replace a face with finished
artwork, add an image using the filename shown below that card in Dev Mode.
Supported formats are PNG, JPG, WEBP, and SVG; WEBP is the default catalog name.

Artwork should use a 5:7 portrait aspect ratio. `GameCard` loads a matching image
automatically and keeps the same sizing, hand layout, and board behavior.
